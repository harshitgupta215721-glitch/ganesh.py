# Neon Sketch Reveal

A Python-based image animation project using OpenCV and NumPy.

## Technologies
- Python
- OpenCV
- NumPy

## Features
- Image processing
- Edge/sketch effect
- Particle animation
- Animated image reveal

## How to Run

Install the required libraries:

pip install opencv-python numpy

Then run:

python particle_animation.py
